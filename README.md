Utilicé una clase abstracta Evento porque Cine, Concierto y Taller comparten atributos como nombre, fecha, precio y cupos. Esto evita duplicar código y permite reutilizar funcionalidades comunes. Además, facilita agregar nuevos tipos de eventos en el futuro implementando únicamente el método CalcularPrecioFinal().
